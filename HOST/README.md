# FZ3B 语义视频工作台 · 2026-10-10

双击 FZ3BVisionConsole.exe，填写板卡 IP 或串口号并连接，无需令牌或密码。主机网口按钮仍支持一键配置，需要时弹出 Windows 管理员确认。

实时录像和上传视频的命中相似度阈值默认 0.17，只用减号/加号以 0.01 步进调整。“连续片段优化”默认开启，减少短暂掉分造成的碎片；关掉可恢复原逐帧阈值切分。任务进行期间参数冻结，结束后可调整。

常用操作：连接板卡 → 输入描述或点击物品与场景预设 → 开始录像与检索 → 结束录像。预设填入和手动描述更新成功会弹窗；开始后按钮立即变为黄色“等待推理”，实际推理运行后变为红框“正在推理”。结束时先保存，保存完整后弹出“录像已结束”，可直接打开保存位置。

四个主要操作均带图标。预设只显示中文名称，连续片段选项收起在“更多设置”。设备参数只保留频率设置和实时显示；相似度在两个业务页面调整。命中时间段仅显示描述、开始和结束时间，画面下方不再显示结果年龄。

视频语义检索页面可选择“当前推理帧”或“整段视频”。整段视频按原速独立播放，可暂停、拖动，不影响板端逐帧检索。选择时间段可播放对应区间，返回画面恢复所选显示方式。

固定每个描述导出一个汇总视频，原始出现区间保留在时间列表和 clips.json；短暂候选仅保存在 candidates.json，不显示、不导出。两个相关复选框已按用户要求移除。

选中条目以明亮蓝色整行高亮；移开焦点仍保持高亮，结果刷新后按描述和原始事件开始时间保留选择，切换录像/分析会话时清除旧选择。

历史实验视频已按用户要求清理。连续片段规则见项目 docs/analysis/2026-10-10-semantic-continuity.md。当前未检测到 USB 串口，串口无令牌实连待 USB 连接后验证。

设备参数每秒更新 CPU 使用率、可用内存、摄像头和推理帧率、R5 状态，以及 CPU 区域 / PS / PL 温度和 8 项供电电压；断线或过期显示横线。CPU 温度是 FPD 区域传感器，不能分别代表四个 A53 核心。

默认板端实际 CPU 1.2 GHz，600/800/1000/1200 四档，调频仍自动停止推理、核验后恢复。模型、PL 和 R5 固件保持原成果。

维护源码在 vision_app，构建入口 vision_app/build.ps1，默认构建到工作区 .build/client/dist，验证后发布到唯一 deliverables/vision-console/FZ3BVisionConsole。重建模型资源取自此唯一客户端目录。

开发环境已清理：先在 HOST 建立 Python3.12 .venv-vision-client，安装 requirements.txt 和 pytest；在项目根执行 HOST 虚拟环境的 python -B scripts/test_final_application.py -p no:cacheprovider。所有回归测试已归入本目录 tests；不再依赖 archives。


推理 FPS 使用板端最近十张图像完成间隔的窗口平均（十个间隔、十一项时间边界）；每次重新推理清空窗口，启动准备时间不计入，窗口未满时显示“采样中”。实时画面、设备页和上传视频分析使用相同口径。

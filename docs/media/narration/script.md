# 2.1 视频解说词

0.60–19.29 秒
应用一，实时文字找场景。输入你要寻找的物品或场景，系统会在摄像头画面中进行语义匹配。这里，我们依次展示鞋子、U盘、鼠标和枕头，演示从文字查询到命中片段保存的完整流程。

32.00–43.28 秒
首先展示鞋子。系统把当前画面的图像特征，与查询描述的文本特征进行比较，再根据设定的相似度阈值筛选命中画面。

54.00–69.52 秒
接着展示U盘。客户端同时显示视频帧率和推理帧率。视频帧率反映画面接收速度，推理帧率反映分析完成速度，两者采用不同的统计口径。

80.00–90.48 秒
现在展示鼠标。右侧可以查看最近分析帧的相似度。这个数值用于语义匹配，不是识别概率，也不等同于准确率。

103.00–112.52 秒
枕头展示完成后，结束本次录像。系统保存收到的完整视频，并保留命中时间段，方便后续回放和整理需要的内容。

127.00–139.88 秒
下方列表记录了不同描述对应的命中区间。选择其中一条记录，就可以回看相关画面，也可以播放选中的时间段，或者导出需要的视频片段。

157.00–173.69 秒
Windows 主机负责中文离线翻译与文本编码，板端由PS和PL协同执行视觉推理。板卡代号是FZ3B，芯片采用 Zynq UltraScale Plus。

186.70–200.53 秒
应用二，视频语义检索。除了实时摄像头，系统也支持分析已有视频。选择文件，再输入要查找的物品或场景，就可以开始按帧分析。

213.00–225.39 秒
本次输入笔记本电脑、鞋子、眼镜和杯子四个描述。客户端读取视频帧，通过以太网发送到板端，利用视觉特征与文本特征完成语义匹配。

242.00–256.88 秒
为便于观看，原始录像中一分零二秒到九分四十秒的处理过程，已经加速十倍。画面上的提示会持续标明加速状态，这一段的播放速度不代表系统实际推理速度。

278.00–292.88 秒
视觉推理采用处理系统与可编程逻辑协同执行。自研RTL加速部分卷积算子，其余模型分区由处理系统完成；双R5核辅助匹配与协议工作。

305.00–323.75 秒
分析完成后，系统列出命中时间段。点击笔记本电脑、鞋子、眼镜或杯子的记录，可以浏览对应画面，并导出需要保留的片段。

331.00–339.80 秒
项目已开源，提供PS、PL和主机端源码。欢迎关注异构计算和边缘人工智能的朋友交流。
